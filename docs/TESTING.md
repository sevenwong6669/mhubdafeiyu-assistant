# 迈从大肥鱼插件：给朋友的测试说明

这份包先重点测试 **Ace 75 键盘和 K20 GT 音箱**。只有其中一台也可以测试对应功能。其他已有适配没有删除，但暂不承诺所有型号都能用。

## 可以直接交给 Agent 的安装要求

> 请先阅读本包的 AGENT-INSTALL.md 和安装与使用.md，检查当前电脑是否已经安装本插件。保留已有配置和数据，将这份包接入 DeepSeek Harness。优先验证 Ace 75 和 K20 GT。现有图标、字体随包保留；桌宠模型和 Cubism Core 为空，不要到作者电脑目录找模型、账号或凭据。安装后打开总览的“首次使用引导”，让我选择自己的账户、收音设备和音色。每一步分别报告配置、服务状态和实际测试结果；不要把没配模型或没接设备说成插件安装失败。

## 从哪里开始

1. 在自己的电脑安装并打开过 DeepSeek Harness、官方 M HUB；安装时还需要 Node.js 22.15+ 和 Python 3.12 x64。
2. 把包解压到长期使用的独立文件夹。请保留整个目录结构，安装方法见《安装与使用.md》。
3. 安装完成后打开 Harness，再打开管理页 `http://127.0.0.1:18782/api/mhub-community/panel`。
4. 在“总览”点击 **首次使用引导 → 开始设置**，按五步完成：连接设备、选择 Harness 来源、余额与音箱、语音、可选桌宠。
5. 不需要的功能可以跳过；总览始终保留重新打开引导的入口。进入设置页后，上方会出现“返回引导”。进度只存在当前浏览器。

账号、密钥、聊天、录音、个人板载备份和作者的设备设置都没放在包里。余额读取自己的 Harness 来源；需要的云服务使用自己的凭据。图标和字体保持当前项目的样式，不换成占位图。

## 先测这几项

| 功能 | 怎么测 | 记录什么 |
|---|---|---|
| 安装和后台 | 按引导打开总览、设置和设备页 | 能否打开，具体错误文字 |
| Ace 75 | 自己开启设备联动，配置余额来源和灯带，再进行一次 8 秒灯光试用 | 灯光是否变化、结束是否恢复、余额是否正常 |
| K20 GT | 切换音箱页面；语音配置完成后说一句话 | 小屏能否切页，有无回复和对应字幕 |
| 语音 | 选好实际麦克风与播放设备、识别模型及音色后，按住语音键说话 | 第一句是否能识别、有声音、有字幕 |
| 恢复 | 先保存工作；允许重启时再测自动启动或点击“重启插件” | 有没有手动恢复，第一句是否正常 |

没有配置识别模型、TTS 或桌宠模型的项目请写“未配置/未测”，不要填写“已通过”。模型为空时，完整桌宠及依赖角色的电话/陪看功能不作为本包默认验收项；设备后台、余额和屏幕可以先独立检查。QQ、付费生图和局域网均为可选，不需要为了完成引导强行开启。

## 遇到问题反馈什么

请提供 Windows、Harness、M HUB 和插件版本、设备型号、做了什么操作、发生了什么、是否能重复，以及不含个人信息的错误截图。不要把 API Key、面板令牌、完整聊天、录音或整个个人状态目录发出去。

这份包用于朋友试用，还没有替代真实新电脑验收。请先正常完成设置，再依次测试，发现异常时保留现场和错误文字。
