# 关节词典（大肥鱼身体的用法说明书）

> 这份文件是给大肥鱼看的：想做一个动作库里去没有的动作时，照着这里的话写。
> 数值全部来自 2026-11-06 的逐参数实测截图（`joint/dict*.png`、`joint/handsweep.png`），不是猜的。

## 一、三种通道：写在哪一层，效果不一样

| 前缀 | 含义 | 什么时候用 |
|---|---|---|
| `d.` | 物理**输入**：角度、前后倾、位移 | 想让她「整个人」动、并且带起头发/耳朵/裙摆的摆动。**做动作优先用这个** |
| `p.` | 参数**覆盖写** | 手臂、手指、手型、胸腔这些关节。写多少就是多少 |
| `a.` | 参数**叠加** | 表情、眉毛、眼睛开合。叠加不会破坏眨眼和说话口型 |

## 二、身体（`d.` 通道，单位是「度」或「像素级位移」）

| 参数 | 正数 = | 负数 = | 常用幅度 |
|---|---|---|---|
| `d.AngleY` | 抬头 / 仰头 | 低头 / 垂头 | ±14 |
| `d.AngleZ` | 头往一边歪 | 往另一边歪 | ±22 |
| `d.AngleX` | 转头看向一侧 | 看向另一侧 | ±20 |
| `d.LeanInput` | **后仰后撤**（人变小、露出腰裙） | **前倾凑近**（压向镜头、画面放大） | ±16 |
| `d.PositionX` | 重心往一侧挪 | 往另一侧 | ±9 |
| `d.PositionY` | 整个人往上浮 | 往下沉（屈膝感） | ±2 |

⚠️ `d.LeanInput` 的符号最容易记反：**负数是往前凑，正数是往后撤**。

## 三、手臂（`p.` 通道，范围都是 -1~1）

这套骨架是**两段式**：大臂抬不起来，小臂怎么动都没用。实测结论：

| 参数 | 作用 | 实测要点 |
|---|---|---|
| `p.Param36` | **右大臂 Z 轴 = 抬右臂** | 这才是「把手举起来」的开关，+1 = 手到耳侧。只写 `RArm` 手只会在身侧张开约 30° |
| `p.RArm` | 右大臂左右张开 | +1 = 手臂往身体外侧甩。**想举高要先给 Param36，RArm 给多了手会被甩出画面** |
| `p.RForearm` | 右小臂 | +1 = 小臂往外/往下伸展 |
| `p.Param41` | 右小臂 Z 轴 | 负值会让小臂往外抬起（摊掌感的来源） |
| `p.RWrist` | 右手腕转动 | 小幅度抖动用它做「摆手」「挠」的细节 |
| `p.Param62` | **左大臂 Z 轴 = 抬左臂** | 同 Param36，管另一只手臂 |
| `p.LArm` / `p.LForearm` / `p.Param60` / `p.LWrist` | 左臂对应件 | 与右侧同义 |

**四条实测配方**（照抄就能用）：

- 手举到头侧打招呼：`Param36: 1.0` + `RArm: 0.2` + `RForearm: 0.6`
- 双手举高（伸懒腰/欢呼）：`Param36: 0.85` + `Param62: 0.8`，`RArm/LArm` **只给 0.1**（给多了手出画）
- 手放胸前：先切形态 `base: "举手"`，再微调 `RForearm: 0.4`
- 招手（手在头侧来回勾）：`Param36: 0.9` + `RArm: 0.9`，然后让 `Param41` 在 0.25↔0.85 之间来回

## 四、手型（只能靠动作切，不能靠参数按）

`base` 三选一，决定「手是哪一套」：

| base | 形态 | 说明 |
|---|---|---|
| `"举手"` | 手放胸前 / 抚胸 | 所有「手在身前」的动作都靠它 |
| `"竖手指"` | 竖食指 | 指人、强调、数数 |
| `"狗尾草"` | 叼着狗尾草 | 得意、悠闲 |
| 不写 | 默认垂手 | 大部分挥手、伸懒腰用它 |

⚠️ **手型有粘性**：切过去之后不切回来会一直留着，两套叠一起手就变形。
渲染页已经自动处理（进新形态前先播「收手/收手指」），但这意味着**动作开头会多 0.38 秒**，
所以同一个动作不要频繁在两种形态之间跳。

## 五、表情（`a.` 通道，叠加，范围 -1~1）

| 参数 | 效果 |
|---|---|
| `a.EyeSmile` | 笑眼（眯成弯的），+0.5 就很明显 |
| `a.ParamEyeLOpen` / `a.ParamEyeROpen` | 眼睛开合，**负值眯眼**（-0.5 = 半闭，害羞/偷笑用） |
| `a.ParamBrowLY` / `a.ParamBrowRY` | 眉毛上下，+ 挑、- 蹙 |
| `a.ParamMouthForm` | 嘴形，+ 笑、- 平/苦 |
| `a.CheekPuff` | 鼓脸（生气/憋笑） |
| `a.LEar1` / `a.REar1` 等 | 兽耳，+0.5 竖起来（好奇/警觉） |

## 六、其它好用的关节

| 参数 | 效果 | 幅度 |
|---|---|---|
| `p.ChestY1` | 挺胸 | 0~0.9 |
| `p.ShoulderY` | 耸肩 | 0~8 |
| `p.HipAngleZ` | 胯部左右摆（摇摆感） | ±6 |
| `p.ChestX1` | 上身左右微摆 | ±0.4 |

## 七、硬限制（做不出来的动作，别硬掰）

- **手够不到腰**：没有「叉腰」的骨骼路径，硬掰会让手臂穿进身体
- **手够不到嘴**：想去掩嘴，正确做法是**低头把脸凑到手边**（`d.AngleY` 负值），不是把手抬到嘴边
- **手臂抬不到正上方**：这套骨架的上限约 45~60°，别写「双手抱头」「举过头顶」
- **手型只有四套**：托腮、抱臂、比心、OK 手势需要新美术，做不出来
